NOTE: Node.js/npm projects do NOT use a requirements.txt (that's a Python convention).

For Docker, you don't manually list these — you COPY package.json + package-lock.json
into the image and run `npm ci` (or `npm install`), and npm installs everything below
automatically. This file is just a human-readable reference/inventory.

DOCKER SETUP (reference)
--------------------------------------------
In your Dockerfile, dependencies are installed via:

    COPY package.json package-lock.json ./
    RUN npm ci --omit=dev    (production image — skips devDependencies)

or for a dev/build image:

    COPY package.json package-lock.json ./
    RUN npm install

You do NOT need to list these packages individually anywhere in Docker —
package.json + package-lock.json already fully describe them.
